# AI-Travel-Planner-Agent
✈️ AI Travel Planner Agent  An AI-powered travel planning web application that generates personalized travel itineraries based on the user's destination, trip duration, and budget.  The project combines Python, Flask, AI Agents, LLMs, and a modern responsive frontend to provide an interactive travel-planning experience
=======
# Agentic AI Project
The AI Agent should:

Accept the destination city.
Accept the number of travel days.
Accept the user's budget.
Think about the request.
Generate a travel itinerary.
Save the itinerary to a file
